# Character from Tripo: reference images

The owner's reference views of the character (an original fictional ~20-year-old man, not a real person), generated
earlier with Higgsfield image models. Inputs for the Tripo multiview image-to-model.

- `refs/body_front.png`, `refs/body_back.png`: full body, A-pose, 2048 px.
- `refs/body_side_left.png`: profile, his left side to camera (he looks toward the left edge of the image).
- `refs/body_side_right.png`: profile, his right side to camera (he looks toward the right edge of the image).
- `refs/face_front.png`, `refs/face_3q_a.png` (looks image-left), `refs/face_3q_b.png` (looks image-right): face
  close-ups, 1024 px, for the face comparison.
