# Kimodo everyday clips for character v4 (work in progress)

Preview only: nothing here is used by the live site. Clips generated with NVIDIA Kimodo (Kimodo-SOMA-RP-v1.1),
retargeted onto the v4 Tripo rig (`docs/design/char-tripo-v4/char_tripo_v4.glb`, 41 bones) and rendered in the room.
The full README (prompts, constraints, licences, pod cost) comes with the remaining clips.

- `clips/b_type.glb`: seated typing and mouse loop, 16 s (30 fps, loops).
- `renders/b_type.mp4`: the clip in the room, two cameras side by side. `renders/b_type_sheet.jpg`: frames from both.
- `qa/b_type_qa.json`: skin vertices vs the chair, desk, keyboard and bed every 0.1 s.
