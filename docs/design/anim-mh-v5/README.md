# MakeHuman room clips on character v5 (work in progress)

Preview only. G2's MakeHuman room clips (preview/room-mh `web/room/mh/`) retargeted onto v5 with finger bones
(G13's `char_tripo_v5_fingers.glb`, preview/char-tripo-v2 cc04574) by `room_build/kimodo/mh_retarget.mjs`, placed on the
live chair (seat 0.505 m) as room-mh places them (lap activities: chair rolled 0.45 m back from the desk), and rendered
on a GPU pod with the book of `props_g2.json`. The clips for the room go to `web/room/mh_v5/` on preview/room-v5.

- `room_read.mp4`: seated reading, two page turns (4.0-6.8 s, 11.5-14.3 s). `room_read_qa.json`: skin vs furniture every 0.1 s.
